Design system

The visual contract of FluentCMS Components: the tokens on this page, then every component with its variants and states, the CSS-only patterns, and four reference screens composed from them. The CSS these pages load, under src/FluentCMS.Components/Styles/, is the library's stylesheet. The switches above set the theme, the density and the direction of every page.

Colour

Every colour holds both themes in one value through light-dark(). A theme is data-fl-theme="light" or "dark" on any ancestor; without it the page follows the system. The values under the names are the ones in use right now.

Contrast

Text has at least 4.5:1 on its background; borders of controls, marks and the focus ring have at least 3:1. The numbers above are measured in the browser. node design/tools/contrast.mjs checks every pair in both themes and fails when one is below its minimum. Disabled colours are exempt.

Space and size

Space is on a 4 px grid, with two half steps for the inside of small things. The number in a name is the multiple of 4 px. Small fixed sizes (a dot, an avatar, a checkbox) come from this scale too.

Focus ring

One ring for everything: a 2 px outline in --fl-color-focus, 2 px away, with a halo in the gap. On a light background the outline carries it, on a dark or coloured one the halo does. It is an outline, so it stays in forced colours. A text control draws the same outline on its border.

Icon family

The two families that were weighed: the same 34 icons from both, at 16 px and at 20 px, and inside buttons.

Lucide ISC licenseChosen
  • Strokes on one 24 px grid: one drawing serves every size.
  • The weight is a token, --fl-icon-stroke, so it can follow the typeface.
  • The style of the reference design.
  • About 180 bytes an icon; the 108 icons of the set weigh 19 kB before compression.
Fluent System Icons MIT license
  • Filled outlines, drawn again for each size: 16, 20, 24 and more.
  • The weight is fixed in the drawing.
  • The look of Microsoft 365, which the admin is moving away from with Fluent UI Blazor.
  • About 400 bytes an icon and size; two sizes of 108 icons would weigh near 85 kB.

Decided: Lucide. It is the style the reference design was chosen in, one drawing covers all sizes, its weight is tunable, and it is the smaller set. Fluent System Icons are well drawn at each size, but they bring a second drawing per size and the look of another product.

Icon set

The set as it stands, in icons/lucide.svg. It is built by node design/tools/icons.mjs from a pinned version; an icon is added to the list in that script, never to the file. The set is trimmed to what the screens use before the library ships it.
