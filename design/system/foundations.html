Foundations

The icon, and the three exemplars that every other component is drawn after: button, field and text input. Then the patterns that everything uses: stack, cluster, divider, link and keyboard key. RECIPE.md is written from this page.

Icon

An <svg> that draws one symbol of the set. It takes the colour of the text around it and one of three sizes.

Small 14 px, medium 16 px, large 20 px; in the colour of the text; spinning

Left to right, then right to left: only an icon marked as directional is mirrored

Spec
Element<svg class="fl-icon"> with one <use> of a symbol. The <svg> has no viewBox; the symbol has its own.
ARIA and keysDecorative by default: aria-hidden="true". With a label it is an image: role="img" and aria-label. It never takes focus.
LevelStatic
Parameters
  • Name: the icon
  • Size: Small, Medium (default), Large
  • Label: text for an icon that stands alone
  • Directional: mirrored in right-to-left
  • Spin: turns, and stops under reduced motion
Classesfl-icon, fl-icon--s, fl-icon--l, fl-icon--directional, fl-icon--spin
Tokens--fl-icon-size-s, -m, -l, --fl-icon-stroke, --fl-duration-spin; own: --fl-icon-size

Spec
Element<button type="button">; type="submit" or "reset" in a form; <a href> when it goes somewhere.
ARIA and keys
  • Native button: Enter and Space. Native link: Enter.
  • Icon only: the name is aria-label, and a tooltip shows it.
  • Toggle: aria-pressed="true" or "false".
  • Busy: aria-busy="true" with aria-disabled="true"; it keeps focus and ignores activation.
  • Disabled: disabled on a button; on a link aria-disabled="true" and no href.
LevelStatic
Parameters
  • Variant: Secondary (default), Primary, Subtle
  • Danger: the destructive tone
  • Size: Small, Medium (default), Large
  • Icon, IconEnd: an icon before or after the label
  • IconOnly: a square with no visible label; Label is then required
  • Href: renders a link; Type: Button (default), Submit, Reset
  • Pressed: makes it a toggle; Busy; Disabled; Block: full width
Classesfl-button; --primary, --subtle, --danger; --s, --l; --icon, --block; part fl-button__spinner
Tokens

  • Type: --fl-font-size-s, -m, --fl-font-weight-medium, --fl-line-height-tight

  • Own: --fl-button-height, -padding, -font-size, -bg, -bg-hover, -bg-pressed, -border, -fg, -fg-hover, -icon

Spec
Element<div> with a <label for>; for a group of controls a <fieldset> with a <legend>. In the markup the order is label, control, error, help, counter, which is the order a screen reader meets them.
ARIA and keys
  • The label names the control through for and id.
  • The control lists the error, the help and the counter in aria-describedby, the error first.
  • Invalid: aria-invalid="true" on the control. Required: required on the control; the asterisk is aria-hidden.
  • No keys of its own.
LevelStatic
Parameters
  • Label; Help; Error: shown when set, or taken from the EditForm
  • Required: shows the mark
  • Hint: short text at the end of the label row, such as Optional
  • MaxLength: shows the counter
  • Horizontal: the layout for settings
  • For: the id of the control, generated when absent
Classesfl-field; --horizontal; parts fl-field__label, __required, __meta (with --over), __error, __help
Tokens

Spec
Element<span class="fl-input"> around <input class="fl-input__control">, with type text, email, url, tel, password or search.
ARIA and keys
  • A native text box, named by the label of its field, or by aria-label outside one.
  • Invalid: aria-invalid="true". Read-only: readonly. Disabled: disabled.
  • An action is a <button> with its own name, after the input in the tab order; a toggle carries aria-pressed.
  • An affix is plain text; when it matters to the value it is part of the label or of the help.
LevelStatic. Posts as a form field in static rendering.
Parameters
  • Value with @bind-Value; Type; Placeholder; Name
  • Size: Small, Medium (default), Large
  • Icon: at the start; Prefix, Suffix: fixed text
  • Clearable: the clear action; a password gets its show action
  • Mono: for code; ReadOnly; Disabled; MaxLength; AutoComplete
Classesfl-input; --s, --l, --mono; parts fl-input__control, __icon, __affix, __action
Tokens
  • Colour: surface, surface-subtle, border-control, border-strong, text, text-subtle, hover, pressed, accent-text, danger-solid, the disabled three
  • Size: --fl-control-height-*, --fl-control-padding-*, --fl-control-radius, --fl-icon-size-m, --fl-space-2, --fl-border-width
  • Type: --fl-control-font-size, --fl-font-size-s, --fl-font-family-mono, --fl-line-height-tight
  • Focus: --fl-focus-ring, drawn on the border of the box
  • Own: --fl-input-height, -padding, -font-size, -inner-radius
